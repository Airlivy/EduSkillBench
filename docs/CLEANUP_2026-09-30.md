# 项目整理与题库修订收敛记录

本轮将工作重点恢复为项目可维护性和测试集内容修复。批量 API 内容复核未产出有效验收记录，已停止，不作为通过证据。

| 问题 | 原因 | 本次处理 |
|---|---|---|
| 未验证的接口试验进入当前评分代码 | 排查输出截断时加入了其他协议、思考参数和超时分支 | 保存试验源码与哈希后，恢复到 v3 对照校准时冻结的评分实现 |
| 测试集版本不清楚 | 多轮修订并列，README 仍主要描述历史实验 | 增加题库说明及版本索引，明确 v4 是当前候选、正式发布状态未开启 |
| 数据检查、重建、汇报各自有脚本 | 工具增长后入口分散 | 加入统一的 `data-check`、`data-build`、`data-report` 命令，均为离线操作 |
| 说明混淆“评分成功”与“题目正确” | 曾把小批对照的通过结果概括得过宽 | README 与当前汇报分别说明结构检查、内容修订、评分校准和正式验收 |
| 修订后难以追踪具体改动 | 仅有汇总说明无法逐字段核对 | 保存当前候选的修改前后差异、修订理由、构建输入哈希和发布门槛 |

未验证的接口实验源文件及整理前副本保存在 `.local-artifacts/content-review-experiment-20260930/`，失败调用记录保存在 `jobs/repair-audit/`。这些都是本地审计材料，不进入推荐运行入口。

本轮没有通过删除数据、清空日志、回退用户工作或提交全部文件来消除 Git 状态。工作区仍有待提交的有效修复，以及此前的论文改动；“未提交”与“工程混乱”应分开判断。

候选题库的改动包括：可替换教学示例、避免跑题因未犯错而得分、去除重复计分条件、修正确定诊断与可选支持、补经济学实例与边界、补命题概念、修复个别翻译和定义范围。具体见题库内容修订报告及逐字段记录。
