# EduSkillBench 测试集验收原则与本轮记录

验收对象是当前 v4 中每一道题的题面、背景、参考答案、评分项及指定 Skill。结论绑定本次文件校验值；任何相关字段修改后，受影响的检查必须重新做。模型得分高、代码测试通过或文件格式正确，都不能单独证明题目合格。

## 验收原则

| 检查项 | 通过要求 | 不通过或待确认的例子 |
|---|---|---|
| 题目能否回答 | 目标和交付物清楚，必要条件充分；开放咨询可以说明合理假设或请求补材料 | 没有提供教案，却要求判定这个教案已经有效 |
| 知识与计算是否正确 | 明确定义、适用条件、单位和边界；数理题另行推导、核算或举反例 | 将必要条件当充分条件；公式成立但漏掉定义域；计算结果错误 |
| 题目、参考、评分是否一致 | 问什么就评什么；没有额外隐藏要求；可选内容不能突然变必选 | 问命题和充分条件，却只评充分条件；示例数字变成唯一答案 |
| 合理答案是否能得分 | 接受等价方法、措辞和例子；不要求每个开放问题都按同一教学套路回答 | 用另一组正确数字或合理教学步骤，就被判不符合参考 |
| 评分能否识别实质错误 | 同版题目配套正确、等价正确、关键错误、跑题四类完整回答，逐项检查评分 | 有知识错误仍通过对应内容项；跑题仅因没有指定错误而拿分 |
| 来源与用途是否一致 | 能核对题源含义和改编范围；学段合理；任务确实要求所测试 Skill 的能力 | 中文问句变成英文既定事实；错因诊断题被当作选择题生成能力测试 |
| 工程记录是否可追溯 | 编号唯一，字段齐全，权重合理，无重复计分，CSV 与编译结果一致；保存证据及版本 | 改了题目但仍沿用旧评分，或只凭题号复用旧验收结论 |

学长的台账是必须逐项回应的检查清单，但其中按旧题号记录的判断不能直接充当新版本结论。存在争议时，以当前题目、题源、推导和具体反例为依据。

## 如何判定

- **通过**：该题所有适用检查完成，证据充分，没有未解决的阻塞问题。结论仅限本版、声明的用途和已覆盖的检查。
- **不通过**：已经找到明确反例、矛盾、知识错误或用途不匹配。修改或调整用途后重新验收。
- **待确认**：尚未完成检查，或证据不足、存在合理争议。不能算通过，也不能直接当成错误。

可以记录“计算专项通过”“结构通过”，但不能把它们缩写成“整题通过”。重大知识错误不能靠格式分抵消；错误回答的其他正确部分可以获得部分分数，但不能因此标成内容合格。对于每题的重要错误类型，应分别检查对应评分项，不以总体平均分代替。

请求超时、空正文、输出截断属于评分执行失败，不是题目零分，也不是题目验收失败。更不能不停重跑、只保留一次符合预期的结果。重复测试应保留全部记录；不稳定则维持待确认。
