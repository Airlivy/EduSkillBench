# EduSkillBench 可运行测试集交付

交付版本：`run-ready-20260930`。验收记录更新于 2026-10-01。

本轮把全部 **305 题**整理成了可运行数据包。已逐题阅读当前题面和参考答案，核对评分锚点，复算数理例子，并完成编译检查。这是可运行交付，不是“所有题经过专家认证”或“以后评分永远不会失败”的保证。

## 交付内容

| 文件 | 内容 | 用途 |
|---|---|---|
| `data/releases/run-ready-20260930/core.csv` | 42 题，14 个 Skill 各 3 题 | 五个模型的有 Skill／无 Skill 对照 |
| `data/releases/run-ready-20260930/advisory.csv` | 263 道扩展教学咨询题 | 无 Skill 回答质量测试 |
| `data/releases/run-ready-20260930/all.csv` | 完整 305 题 | 一次运行全部题目的回答质量测试 |
| 同目录 `evals.json` | 与 CSV 一致的题面、参考、完整加权评分项 | 程序读取 |

没有删除扩展题。分开用途，是因为“如何处理课堂问题”等咨询并不都要求生成指定 Skill 的完整交付物，直接混进同一个 Skill 提升分数会产生误导。原编号保留，便于对照学长的建议；扩展题原来的 Skill 字段作为历史标签保留，不作为经过验收的正确路由。

## 本次又修复了什么

- 运行入口原来默认读旧题库，现在 `run`、`prepare` 默认读取这次交付的主测试集，并显示实际路径与版本校验值。
- 修正了 47 题的字段。其中主集统一要求实质回答并新增关键正确性项，原维度保留 80 分，关键项 20 分；这不是发现了 47 个知识错误。
- 修正语法干扰项要求“语法形式完全相同”的矛盾；不再强制每个误区都有多道题、不再要求某个固定心理支持方法。
- 开放讨论允许澄清事实；四级提示允许最终步骤串起来；电磁感应题必须覆盖明确要求的四个概念步骤。
- 中位线明确为三角形中位线；主元法明确本改编的入门范围；修正双曲线坐标约定、角色抽签和课堂口令的评分措辞。
- 修复 Dockerfile 把镜像 ID 当仓库名的构建错误，并让本地 Docker 网关健康检查绕过外部 HTTP 代理。
- 新运行由容器生成答案，再由主机统一评分。评分请求只在一层重试，单次评分最多请求三次；失败保留答案和原因，不生成假 0 分。再次执行同一批次时，优先补评分，不重新生成已有的有效答案。
- 运行时绑定完整题目内容，避免只比较题号、改了评分项还接着使用旧运行目录。
- 所有运行结果写入新标签目录，旧题库和旧实验结果保留。

环境文件中的旧地址仍是 `/api/coding`，本次试验该地址返回 401；命令显式使用用户提供的 `/api/plan/v1`。程序只读取变量赋值，不执行整个 `.bashrc`，报告和数据包不包含密钥。

检查与汇总对应的新任务：


## 验证记录与结论范围

离线验证：全部 305 题的编号、非空字段、评分项、权重、参考对应关系、题源快照、逐题记录校验值通过；复用学长的结构检查。五模型主集的 access、forced 两种模式分别完成 420 个任务的生成与检查，全量无 Skill 集完成 1525 个任务的生成与检查。这些是离线编译数量，不是已完成的付费实验数量。

完整数值核算及运行检查见 `docs/data-quality/RUN_READY_VALIDATION_2026-09-30.json`；最新 58 项工程测试与 27 项数据测试通过，另有 34 项独立数值核算通过；内容核对依据见 `docs/data-quality/RUN_READY_CONTENT_NOTES_2026-09-30.md`。

真实端到端检查已完成，使用 `glm-5.3-flash`：

| 实跑范围 | 结果 | 说明 |
|---|---|---|
| 主集 `differentiation-adapter__01`，无 Skill／有 Skill 两个条件 | 2/2 有效评分，均为 1.0，关键项通过 | 较早的运行流程；无 Skill 的容器评分超时后，用保存的答案在主机补评分成功 |
| 扩展集 `project-brief-designer__cn52_04`，无 Skill | 1/1 有效评分，为 1.0，关键项通过 | 最终主机评分流程；容器只生成答案，主机首次评分成功，没有容器评分请求或假 0 分 |

这三条记录证明对应流程可运行，不代表五个模型的全量实验完成。真实评分对照抽测中，两个模型的正确答案样例得到有效评分，错误答案样例遇到请求超时，未完成预定对照；不能据此宣称评分器已充分校准。完整记录在 `docs/data-quality/RUN_READY_DELIVERY_STATUS_2026-09-30.json`，绑定原始结果及评分文件的校验值。

原来的完整验收原则依然有效：目前不声称完成 305 题各四类回答的真实校准，也不将同一个模型的抽测说成独立专家认证。外部 API 超时仍可能发生；现在区分“待评分”和“回答确实得 0 分”，保存已有答案并支持单独补评分。

数学与物理核算使用题内假设。SIR 例题的增长率与 R0 关系核对了 [Wallinga 与 Lipsitch 的研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC1766383/)，磁通积分与感应电动势核对了 [OpenStax 法拉第定律](https://openstax.org/books/university-physics-volume-2/pages/13-1-faradays-law)。具体数值重新计算，记录在上述验证文件。
