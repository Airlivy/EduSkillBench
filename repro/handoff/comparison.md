# 本机与 GitHub 发布版全量对照（2026-10-04）

结论：**当前 Chat 评测所用项目代码、正式配置、305 题发布数据和 Skill 已随本次发布交接；整台机器及历史容器环境并不等同于 GitHub 仓库。** 特别是 BenchFlow 本地补丁、容器/宿主 OpenCode 版本差异、缓存服务和权限问题，不能靠“安装相同版本”自动消除。

## 对照范围及方法

对本机项目 `/home/airlivy/EduSkillBench` 递归列出所有文件（含被 Git 忽略的目录，排除 `.git` 元数据）；与独立发布工作目录实际 Git 索引逐项对比。两边都有的文件比较 SHA-256，记录大小与权限；本机独有文件只记录路径、大小、权限，不复制内容或计算私密文件哈希。没有把整个 `/home` 或操作系统称为已逐文件审计。

结果：两边相同 **406** 个；两边不同 **9** 个；发布版独有 **103** 个；本机独有 **105023** 个。比较报告自身 3 个文件不参加自身哈希统计。明细见 [file-comparison.csv](file-comparison.csv)，机器可读汇总见 [comparison-summary.json](comparison-summary.json)。CSV 较大，是十万余条文件目录记录，不包含原始运行日志正文。

## 验证结论

工程测试 116/116 通过；正式离线计划正确生成 3050 位置、610 提示词、14 个 Skill。数据测试在恢复题源后 40/42 通过，剩余是历史证据未迁移、裁决记录 manifest 绑定过期，详细记录见 [validation.md](validation.md)。CSV 与 JSON 的 305 行全部原字段等价。

**可以交接当前 Chat 运行材料，但不能说上传后整个环境已完全一致，更不能说学长的容器复现已通过。** 下一台机器首先需要确认自己的容器版本、缓存安装策略、Skill 可读与注册、失败轨迹导出；三组端到端验证通过后再开展其全量实验。
